# Frontend

Ollie plans to deliver the dashboard and user interface here. The page in `backend/public/` is a local legacy demo and is disabled in MVP mode; it is not the team frontend. The confirmed MVP fields and review rules are in [`docs/product.md`](../docs/product.md). A new report needs only `description`; `projectId`, `incidentType`, `targets[]`, and `evidence[]` are optional. New reports remain private. The web app must use a trusted Discord identity integration for reporter-linked requests rather than a typed reporter name; the current backend accepts submissions from a trusted Discord bot adapter but has no direct web auth flow. The MVP API contract is [`backend/mvp-openapi.json`](../backend/mvp-openapi.json). [`backend/openapi.json`](../backend/openapi.json) describes the older demo only.
